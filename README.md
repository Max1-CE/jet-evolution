# Як еволюціонував реактивний двигун

Серія з п'яти інтерактивних ізометричних фігур українською мовою: від Jumo 004B (1944) до PW1100G з редуктором вентилятора. Двигуни стоять на одному випробувальному стенді й намальовані в одному масштабі (1 м = 62 одиниці).

| Сторінка | Що показує |
|---|---|
| `docs/fig-1-evolution.html` | Чотири двигуни в розрізі; повітря зовнішнього контуру й ядра окремо; m, π, Tг, Cуд, ηt, ηp. Двигун розбирається на модулі (кнопка або E) |
| `docs/fig-2-cycle.html` | Манометри й термометри під станціями 2, 13, 3, 4, 5 — цикл Брайтона |
| `docs/fig-3-propulsive.html` | Гребінка за соплом і швидкісна дошка: v0, vвент, vядра, vj — пропульсивний ККД |
| `docs/fig-4-gearbox.html` | Зірчастий планетарний редуктор 98/32 = 3,0625, п'ять сателітів |
| `docs/fig-5-hot-section.html` | Лопатка турбіни в розрізі: чотири покоління охолодження |

## Збірка

Потрібен Node 20+; залежностей немає.

```sh
node build.mjs        # усі сторінки в docs/
node build.mjs 2 4    # лише Рис. 2 і Рис. 4
node src/check.mjs    # звірка моделі з опублікованими даними
```

## Будова

- `src/model.mjs` — дані двигунів і цикл: ηt = 1 − π^(−(γ−1)/γ), ηp = 2/(1 + vj/v0), питома витрата палива з ККД вузлів своєї епохи. `check.mjs` порівнює модель з даними (розбіжність ≤ 6 %).
- `src/engines.mjs` — меридіональна геометрія двигунів у метрах.
- `src/render.mjs` — двигун у розрізі: задня половина, лопатки, площина розрізу.
- `src/stand.mjs`, `src/flow.mjs`, `src/live.mjs`, `src/page.mjs`, `src/style.mjs` — стенд, лінії течії, живий скрипт, оболонка сторінок.
- `figs/fig1.mjs … fig5.mjs` — окремі фігури.
- `vendor/anatomy/` — копія набору [anatomy](https://github.com/wheresryan22/anatomy) (MIT, © 2026 Ryan).

Температура перед турбіною для JT8D, JT9D і PW1100G та крейсерська витрата палива PW1100G — оцінки (виробники їх не публікують); на сторінках вони позначені зірочкою. Джерела наведено під кожною фігурою.
