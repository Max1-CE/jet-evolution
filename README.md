# Як еволюціонував реактивний двигун

Серія з шести інтерактивних ізометричних фігур українською мовою: від Jumo 004B (1944) через військовий F135 з форсажною камерою (2009) до PW1100G з редуктором вентилятора. Двигуни стоять на одному випробувальному стенді й намальовані в одному масштабі (1 м = 62 одиниці).

На кожній сторінці апарат відкривається в повноекранному 3D (кнопка «3D» або R): його можна обертати, запускати (S: ротори розкручуються кожен зі своїм валом, вентилятор PW1100G — через редуктор у зворотний бік; повітря тече крізь двигун: синє — зовнішній контур, жовте — ядро, червоне — газ після камери; на лопатці Рис. 5 — «Подати газ»: гарячий газ обтікає перо, охолоджувальне повітря йде каналами від хвостовика й виходить на кінці або плівкою з отворів; на редукторі Рис. 4 — масло: крізь опору й плиту водила в порожнисті осі, до підшипників ковзання сателітів і форсунками в зачеплення), вмикати й вимикати розріз, розбирати на модулі, вузли й окремі деталі (аж до однієї лопатки з полицею й хвостовиком) — з функцією, матеріалами й даними кожної частини. На 2D-фігурі на Рис. 1–3 E розбирає двигун, а клік по модулю відкриває його в 3D.

## Збірка

Потрібен Node 20+; залежностей немає (three.js лежить зібраним у `vendor/three/`, збірка копіює його в `docs/vendor/`). 3D-переглядач — ES-модуль, тож локально сторінки треба відкривати через HTTP-сервер (`python -m http.server -d docs`), а не з файлу.

```sh
node build.mjs        # усі сторінки в docs/
node build.mjs 2 4    # лише Рис. 2 і Рис. 4
node src/check.mjs    # звірка моделі з опублікованими даними
```

## Будова

- `src/model.mjs` — дані двигунів і цикл: ηt = 1 − π^(−(γ−1)/γ), ηp = 2/(1 + vj/v0), питома витрата палива з ККД вузлів своєї епохи. `check.mjs` порівнює модель з даними (розбіжність ≤ 6 %).
- `src/engines.mjs` — меридіональна геометрія двигунів у метрах.
- `src/render.mjs` — двигун у розрізі: задня половина, лопатки, площина розрізу.
- `src/stand.mjs`, `src/flow.mjs`, `src/live.mjs`, `src/page.mjs`, `src/style.mjs` — стенд, лінії течії, живий скрипт, оболонка сторінок.
- `src/explode.mjs` — розбирання 2D-двигуна на модулі (Рис. 1–3).
- `src/catalog.mjs` — дерево деталей двигунів для 3D: геометрія, зсуви для розбирання, функція й матеріали; дерева редуктора й лопатки — у `figs/fig4.mjs` і `figs/fig5.mjs`.
- `src/viewer.mjs`, `src/viewer-app.js` — повноекранний 3D-переглядач (three.js): тіла обертання, лопатки як InstancedMesh, розріз площинами, що їдуть разом із деталлю. Тестові хуки — `window.__viewer` (`open(i, path)`, `explode(on, deep)`, `cut(on)`, `enter(...)`, `blade(i)`, `settle()`).
- `figs/fig1.mjs … fig5.mjs` — окремі фігури.
- `vendor/anatomy/` — копія набору [anatomy](https://github.com/wheresryan22/anatomy) (MIT, © 2026 Ryan).
- `vendor/three/` — [three.js](https://threejs.org) r187 з OrbitControls і RoomEnvironment, зібраний esbuild в один файл (MIT).

Температура перед турбіною для JT8D, JT9D і PW1100G та крейсерська витрата палива PW1100G, а також π вентилятора F135 і його витрата палива без форсажу — оцінки (виробники їх не публікують); на сторінках вони позначені зірочкою. Джерела наведено під кожною фігурою.
